# EUM Mid Term Examination

Professional 1920x1080 Mid Term Examination date-sheet display for Emerson University Multan.

## Source

Official **CSET Mid Term Examination Fall 2026** date sheet for the Faculty of Computing & Emerging Technologies, effective 07 September 2026.

## Exam period

**28 October 2026 – 06 November 2026**

## Automatic behavior

- Uses the Raspberry Pi system clock.
- Shows the current Pakistan date and time.
- Automatically rotates through examination sections.
- Highlights the **NOW** examination when the selected section has an exam in progress.
- Shows the **NEXT** upcoming examination.
- Shows exam date, time, course code, course title, room and invigilator.
- Works offline because the exam data is bundled in `exam.json`.
- Designed for 1920x1080 displays.

## Data

The supplied official PDF was converted into `exam.json`.
